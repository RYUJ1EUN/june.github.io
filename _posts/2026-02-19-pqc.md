#### Game-based Security

비밀 정보를 지닌 Challenger와 그 비밀을 탈취하려는 Attacker 간의 싸움을 모델링한 것

##### Attacker (Adversary)

- 공개 정보 획득 가능

- 공격자의 능력이 특정 오라클 형태로 제한됨
- 공격자의 모든 행동은 다항식 시간 알고리즘으로 표현되어야 함


##### PKE/KEM 안전성 정의

- 공격자는 특정 메시지에 대한 캡슐화를 할 수 있음
- 공격자는 특정 암호문에 대한 복호화를
    - 할 수 없음: IND-CPA
    - 할 수 있음: IND-CCA1
    - 암호문을 추측하여 암호화, 복호화를 할 수 있음: IND-CCA2
- $\text{Adv}^{\text{IND-win}}({\cal A}) \ge \frac{1}{2}$일 때 안전하다고 함
    - $\text{Adv}^{\text{IND}}({\cal A}) = \Pr[\text{Exp}^{\text{IND-1}}(A)=1]-\Pr[\text{Exp}^{\text{IND-0}}({\cal A})=1]$
    - $\Pr[\text{Exp}^{\text{IND-1}}({\cal A})=1]-\Pr[\text{Exp}^{\text{IND-0}}({\cal A})=1] < \epsilon$ (공격자가 0,1을 구별할 수 없음)
    - $\text{Adv}^{\text{IND-win}}({\cal A}) = \frac{1}{2}\left( \text{Adv}^{\text{IND}}({\cal A}) +1\right)$



##### 전자서명의 안전성 정의

- 공격자는 특정 서명에 대한 검증을 요청할 수 있음
- 공격자는 특정 메시지에 대한 서명을 
    - 요청할 수 없음: UF-NMA
    - 요청할 수 있음: UF-CMA
    - 동일 메시지에 대한 반복 서명을 요청할 수 있음: SUF-CMA


#### Lattice

- $n$-차원 격자: discrete additive subgroup of $\mathbb{R}^n$
- periodic grid

##### 주요 격자 문제

- SIVP (Shortest Independent Vectors Problem)
- **SVP** (Shortest Vector Problem)
- CVP (Closest Vector Problem)
- uSVP (unique SVP)

##### SVP

- 가장 짧은 0이 아닌 격자 벡터는?
- $\text{SVP}\_\gamma$
    - 적당히($\gamma$) 짧은 0이 아닌 격자 벡터는? 
    - 즉, 가장 짧은 벡터의 크기가 $\lambda_1$일 때, $0<\|v\|\le\gamma\cdot\lambda_1$인 $v$를 찾는 문제
    - 특정 범위의 작은 $\gamma$에 대해 NP-Hard

##### SIS (Short Integer Solution)

- $\mathbb{Z}\_q$ 상의 선형 방정식의 짧은 벡터 해 찾기
- 행렬 $A\in{\mathbb{Z}\_q}^{n\times m}를 기반으로 격자 생성 가능  
    $${\mathcal{L}\_{q}}^\perp (A) := \{ \vec{z}\in\mathbb{Z}^m \mid Az=0 \mod q \}$$
- 랜덤 행렬 $A$에 대한 SIS 문제의 난이도가 가장 어려운 SIVP 문제의 난이도보다 높음

##### LWE (Learning With Errors)

- 작은 error를 `Gaussian dist.에서 랜덤하게 선택한 error` 포함한 연립선형방정식의 해를 구하는 문제
- error $e$를 포함하게 만든 $(A,b=Ax+e)$와 랜덤하게 생성한 $(A,b)$를 구별하기 어려움
    $${\mathcal{L}\_q}^\perp (A) := \{ \vec{z}\in\mathbb{Z}^m \mid z^t=s^t A \mod q \}$$
- LWR (Learning With Rounding): 반올힘한 error를 사용
- MLWE (Module LWE): 다항식 환 위에서 정의


##### 격자기반 난제의 난이도

- dimension $n$이 클수록 어려움
- modulus $q$가 작을수록 어려움
- (Gap)SVP: $\gamma$가 작을수록 어려움
- SIS: 해의 크기가 작을수록 어려움
- LWE: 비밀키/오류 크기가 클수록 어려움
