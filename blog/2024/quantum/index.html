복소수의 크기는 그 자체로 구할 수 없기 때문에 wave func의 density를 논하기 위해서는 제곱이 필요

11쪽

operator (오른쪽 하단 식)

$\text{operator}\times\psi(x) = \text{vector}\times\psi(x) = \text{value}\times\psi(x) = \text{energe}\times\psi(x) = E\times\psi(x)$

operator는 에너지를 나타냄

구체적인 행렬로 표현되면 에너지 벡터이고 연산자로 나타나있을 땐 energe operator라고 함

⇒ 이를 Hamiltonian이라고 함 = 에너지를 알려 주는 연산자 (에너지의 operator $\hat{E}$)

hat은 operator를 구별하기 위한 표기

operator를 discrete하게 만들면 행렬로 표현할 수 있음 (eigen value)

행렬이 바뀌면 eigen vector와 eigen value가 바뀌는 것

→ Hamiltonian을 풀면 에너지 값(실수)을 구할 수 있음

12쪽

⇒ 위치-운동 관계에서 불확정성이 성립한다는 사실은 두 에너지 장의 관계가 commute하지 않음을 의미함

⇒ 두 operator가 commute하면 같은 eigen func를 가짐

13쪽

R.V는 실제로는 함수이지만, 어떤 값에 대한 대응되는 특정 값을 가지는 가측 함수이기 때문에 원하는 값에 대한 대응되는 값만이 결과로 보여 value처럼 받아들여짐

14쪽

양자역학에서 위치를 측정한다는 것은 원자 단위의 측정을 수행해야 하는 것이지만, 이 단위로 측정할 수 없으므로 (측정 단위가 더 큼) 확률 분포(기댓 값)를 구함

⇒ operator를 정의하여 평균과 분산을 구함

→ 운동량과 위치 에너지 등이 확률적으로 기술될 수밖에 없음

$ \psi ^2 = \psi^*\psi$, $\int \psi ^2dx=\int\psi^*\psi \,dx$

⇒ Continuous R.V.에 대응

물리적 환경에서 paritcle이 어떤 두 지점에서만 존재할 수 있다면(two-state system ; qubit), Discrete R.V.에 대응됨

If there exist point over the system set ${x_0, x_1}$, define the $\psi(x_0),\psi(x_1)$,

then $\psi(x_0)^\psi(x_0)+\psi(x_1)^\psi(x_1)=1$

$x_i$가 R.V.라는 것을 강조하기 위하여 $\left x_i \right>$로 표현 : state, vector 표현

$x_i$ point에 있는 상태(state)

$\psi(x_i)\left x_i \right>$ : 확률 진폭 $\psi(x_i)$의 queantum particle이 point $x_i$에 존재하는 상태

18쪽

operator A의 불확정성

$(\Delta A)\psi \overset{\Delta}{=} \sqrt{\left< A^2 \right>\psi - \left< A \right>^2_\psi}$

기댓값으로부터 얼마나 멀리 떨어져 있는지 = $\Delta$

불확정성이 0이면 가장 좋음

그러나 위 식의 우변이 0이 아니면, 불확실성을 줄일 수 없음

a : down, a dagger : up

a dagger : commutation 값이 1이 되도록 nomarigation 한 값

물리적인 의미는 없으나, 수학적 연산을 위해 필요한 값으로 정의됨

25-26쪽

Harmonic Oscillator에서는 등간격 에너지 증가

입자가 가질 수 있는 에너지는 discrete함

Two-state system은 ground state와 1st excited state만 가지도록 설정한 system

두 energe state 사이에 있을 확률을 가지는 경우, 확률적으로 중첩된 상태 (qubit)

관측된 에너지는 무조건 두 불연속적인 값 중 하나를 가짐

전자기 운동은 Harmonic Oscillator 성질을 가짐

⇒ 초전도체를 이용한 qubit 개발

27쪽

orthonomal한 벡터를 기저로 갖도록 2차원 qubit을 표현하면 수학적 계산이 쉬워짐

28쪽

two-state system에서 변수(입자)가 많아지면 표현 가능한 state의 종류가 지수적으로 증가함

입자의 tensor product가 state 기댓 값을 결정함

0, 1 → 00, 01, 10, 11 → …

qubit (bit)

논리적 qubit

알고리즘화 된 추상적 입력 값, 입력에서 오류가 있을 것으로 생각하지 않음

물리적 qubit

(디지털 bit계에서는 오류 발생 확률이 없음) 실제 전기 흐름에 의한 입력 값

양자 컴퓨터에서는 의도하지 않은 연산이 일어날 (오류 발생) 확률이 높음

⇒ 여러 큐비트를 사용하는 전체 시스템 수준에서는 오류 확률이 매우 높아짐

⇒ 논리적 큐비트 수준으로 올라가야 의미있는 양자 컴퓨터를 만들 수 있음

논리적 큐비트 100개를 정의하려면 물리적 큐비트 10000개가 필요함

(오류 정정 과정이 추가되면 상쇄되는 물리적 큐비트가 생김)

29쪽

$\left \psi \right> = \alpha\left 0 \right> + \beta\left 1\right> = \cos\frac{\theta}{2} \left 0 \right> + e^{i\phi}\sin\frac{\theta}{2}\left 1\right>$

슈뢰딩거 방정식의 계수가 복소수 → 두 state에 대한 2차원 표현 불가

alpha, beta 각각 phase factor $e^{i\phi}$가 필요함

qubit state의 표현 : 구의 표면에서 위치하는 지점을 표현하는 것과 같음

실수-복소수 4차원의 3차원 표현 (복소수 2차원 실수 1차원)

30쪽

gate : 선형 시스템

X gate : NOT

orthonormal basis sum이 입력되면 0→1, 1→0으로 바뀌고 계수는 그대로 붙음

$\alpha\left 0 \right> + \beta\left 1\right> \rightarrow \alpha\left 1 \right> + \beta\left 0\right>$

Z gate : 1을 -1로 바꿔줌

H gate : Hadamard gate

0 → + / 1 → - / + → 0 / - → 1

즉, $H^2=I$ ($a → H → H → a$)

31쪽

CNOT gate : controlled-not gate : XOR

controll 0 : target을 그대로 출력

controll 1 : target을 반전시켜(NOT) 출력

controll이 상수인 경우

controll이 1인 CNOT 연산을 수행하면 controll은 상수이므로 변하지 않지만, target state는 1에의해 뒤바껴(NOT) 나옴

32쪽

controll이 중첩된 경우

target state는 controll의 중첩 확률에 따라 결정됨

e.g. controll $\alpha\left 0 \right> + \beta\left 1\right>$, target $\left 0 \right> = \left[0 \ 1\right]^T$
return $\alpha\left 0 \right>\left 0 \right> + \beta\left 1\right>\left 1 \right> = \alpha\left 0 0 \right> + \beta\left 1 1 \right>$

(두 큐빗이 얽힌 상태, tensor product)

$\alpha\left 0 0 \right> + \beta\left 0 1 \right> + \gamma\left 1 0 \right> + \delta\left 1 1 \right>$ : 얽히지 않은 상태

(모든 상태가 나올 수 있음, 계수의 합은 1)

수학적으로 얽힘을 만드는 것은 쉬운데, 현실적으로 CNOT gate를 만드는 것이 어려워서 얽힘을 만들 수 없음

양자 얽힘

여러 큐비트에 대하여 가능한 모든 state 중 가능한 state 일부의 확률을 없애 출력 state의 종류가 줄어든 상황

여러 발생 가능한 확률 변수 중 일부의 확률을 0으로 조정한 것

33쪽

회로도

$-$ 양자 상태 연산

$=$ 디지털 상태 연산

Quantum Teleportation

얽힌 state를 전달하고 한쪽에서 관측하며 중첩 상태가 붕괴되면 반대쪽으로 간 양자의 state도 붕괴되면서 결과를 공유하게 됨

CNOT gate를 거쳐서 하나의 qubit을 상태가 얽힌 두 개의 qubit으로 만들면 두 사용자가 얽힌 state를 가진 qubit를 관측하여 디지털 값으로 나눠가질 수 있음

수신한 값을 다시 gate를 통해 디지털화하기 전 값으로 만들고, 상대의 state가 무엇인지 알 수 있음

ppt의 예제에서 측정한 결과가 00이면 보내려고 했던 값은 $\alpha\left 0 \right> + \beta\left 1 \right>$였던 것임을 별도의 작업 없이 알 수 있음
관측 결과가 10이면 Z연산을 수행해야 $\alpha\left 0 0 \right> + \beta\left 0 1 \right>$를 얻을 수 있으므로 Z 연산을 추가로 작업하여 원하는 $\psi$ 값을 얻을 수 있음

관측 결과는 $\alpha, \beta$에 의한 확률로 관측됨

양자 상태는 복사될 수 없음 (두 양자가 얽힌 상태일 때 한 쪽을 붕괴시켰는데 다른 쪽이 state가 정해지지 않은 양자로 둘 수 없음)

얽혀있는 상태를 재료 삼아서, 상태가 동시에 관측될 수 있도록 만드는 것

$\frac{\left 00\right>+\left 11\right>}{\sqrt{2}}$ : 얽힌 두 양자 중 하나가 0으로 관측되면 다른 하나도 0, 하나가 1로 관측되면 다른 하나도 1인 경우만 존재하는 상태

3개의 양자를 얽히게 하는 예제의 Step 2에서 얽힘을 준비하고 Step 3에서 얽힘을 수행함

H gate는 얽힘이 사라진 것처럼 보이게 만들지만(가능한 state가 많아지는 것처럼 보임) 두 개의 얽힘을 유지하면서 새로운 state를 보이게 만듦….?

34쪽

얽힘은 기술의 한계로 단거리로 만들게 되는데, swapping을 통해 장거리 얽힘을 수행할 수 있음

A ←얽힘 → B ← Swapping → C ← 얽힘 → D

현실에서는 얽힘을 여러 개 만들고 오류 정정을 수행함 → 얽힘 정제 (distillation, purifillation)

전송 중 발생하는 얽힘의 오류를 정정해줘야 함

2쪽

양자 알고리즘

FTQC(Fault-Tolerant Quantum Computer)

오류가 발생해도 하드웨어적으로 오류를 모두 처리한 후 결과를 출력하는 컴퓨터

고전 컴퓨터에서는 자연스러운 기능이지만, 양자 컴퓨터에서는 오류가 정정된 결과가 출력됨을 보장하는 것이 쉽지 않음

Shor’s algorithm

소인수분해 - 암호계, QFT, Phase estimation(eigen value 구하기)

Grover algorithm

데이터 검색

역행렬 계산 - 오류 정정

2040년 정도가 되어야 구현 가능할 것으로 예상됨

NISQ(Noisy intermediate-scale quantum)

현재 구현 가능한 오류가 일부 있는 컴퓨터

연산 중 오류가 발생할 수 있는 10000개에서 100000개의 큐비트를 이용하여 적은 수의 비트 연산 기능을 수행하는 컴퓨터

3쪽

QFT

$2^N$개의 함수 $f_i$의 중첩을 $N$개의 qubit으로 표현

DFT에서 $2^N-1$번의 덧셈으로 표현한 함수의 중첩을 $N$개의 qubit으로 한 번에 표현 가능함 (비트로는 $N2^N$개의 비트 필요)

7쪽

VQA - NISQ 상에서 연산 가능한 알고리즘

양자와 관계없이 고전 컴퓨터에서도 수행 가능한 알고리즘

함수를 인자로 받아서 minimum 또는 maximum을 갖는 함수를 구하는 함수

8쪽

Hamiltonian : 에너지의 행렬 함수

주어진 시스템에서 에너지 총 합의 기대값이 최소 또는 최소가 되는 함수를 구하는 데 사용

즉, 주어진 문제를 풀기에 적합한 Hamiltonian을 찾는 것이 선행되어야 하는데, 이를 푸는 데 VQA가 사용됨

그래프의 경로를 찾는 등의 NP 문제를 풀기 위한 Hamiltonian을 찾아내는 문제

에너지의 기댓값은 가질 수 있는 ground expectation보다는 크거나 같음

⇒ 최소값을 찾는 문제

⇒ Hamiltonian 함수는 주어지고 wave func $\psi$를 구함

10쪽

Adiabatic Thm

어떤 입자가 특정 위치 에너지를 갖는 ground state에 있다고 가정

이때, 가정과 같은 단순한 형태는 아닐 것임

⇒ 미분방정식을 풀어서 실제에 가까운 형태의 식을 구함

처음에는 쉬운 형태의 식을 가정하고 시간에 따른 식의 변화를 천천히 주입하면 입자의 상태는 round state에 위치함 (빠르게 변경하면 ground state에서 벗어남)

11쪽
